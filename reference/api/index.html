SiennaConfig¶

class r2x_sienna.SiennaConfig(*, models=('r2x_sienna.models',), config_path_override=None, model_year=None, system_name=None, json_path=None, output_path=None, scenario='base', system_base_power=100.0, skip_validation=False)[source]¶

Configuration for Sienna model parser.

This configuration class defines all parameters needed to parse Sienna model data, including year information and model-specific settings. Model-specific defaults and constants should be loaded using the load_defaults() class method and used in parser logic.

Parameters:

  • model_year (int | list[int]) – Model solve year(s) (e.g., 2030, [2030, 2040, 2050])

  • system_name (str, optional) – Name of the power system

  • scenario (str, optional) – Scenario identifier

  • system_base_power (float, optional) – System base power in MVA for per-unit calculations

  • skip_validation (bool, optional) – Whether to skip validation during parsing

  • models (Annotated[tuple[str, ...], FieldInfo(annotation=NoneType, required=False, default=('r2x_sienna.models',), description='Module path(s) for Sienna component classes')])

  • config_path_override (Path | None)

  • json_path (Annotated[str | None, FieldInfo(annotation=NoneType, required=False, default=None, description='Path to JSON data file')])

  • output_path (Annotated[str | None, FieldInfo(annotation=NoneType, required=False, default=None, description='Path for output JSON file')])

Examples

Single year with custom base power:

>>> from r2x_sienna import SiennaConfig
>>> config = SiennaConfig(
...     model_year=2030,
...     system_name="EI_Sys",
...     system_base_power=100.0,
...     skip_validation=False,
... )

>>> assert config.model_year == 2030

Multiple years:

>>> config = SiennaConfig(
...     model_year=[2030, 2040, 2050],
...     system_name="Case5_PJM",
...     skip_validation=False,
... )

>>> assert config.model_year == [2030, 2040, 2050]

SiennaExporter.run(*, ctx=None)[source]¶

Execute plugin lifecycle.

Hooks are called in fixed order. Unimplemented hooks are skipped. If any hook returns Err, execution stops and PluginError is raised. Context is updated in-place for memory efficiency.

Parameters:

ctx (PluginContext[ConfigT] | None) – Context to use. If None, uses context from from_context().

Returns:

The context (updated in-place).

Return type:

PluginContext[ConfigT]

Raises:

PluginError – If any hook fails.

Examples

>>> from r2x_core import Plugin, PluginContext, PluginConfig, System
>>> from rust_ok import Ok

>>> class Config(PluginConfig):
...     pass

>>> class MyPlugin(Plugin[Config]):
...     def on_build(self):
...         return Ok(System(name="test"))

>>> ctx = PluginContext(config=Config())
>>> result = MyPlugin.from_context(ctx).run()
>>> result.system.name
'test'
